# Handwritten Numbers Recognition

Machine Learning project for handwritten digit recognition using the MNIST dataset.

## Overview
This project implements and evaluates classic machine learning algorithms for image classification and pattern recognition. The goal is to recognize handwritten digits from the MNIST dataset through data preprocessing, feature extraction, and classification techniques.

## Implemented Algorithms
- K-Nearest Neighbors (KNN)
- Nearest Centroid Classifier

## Technologies Used
- Python
- NumPy
- scikit-learn

## Features
- MNIST dataset loading and preprocessing
- Feature extraction and normalization
- Model training and evaluation
- Classification accuracy comparison

## Project Structure
```text
src/
│── data_loader.py
│── features.py
│── knn.py
│── nearest_centroid.py
│── main.py
```

## Dataset
The project uses the MNIST handwritten digits dataset provided through scikit-learn/OpenML.

## How to Run
1. Clone the repository:
```bash
git clone https://github.com/Giannis-dot/Hand-written-Numbers-Recognition.git
```

2. Install dependencies:
```bash
pip install numpy scikit-learn
```

3. Run the project:
```bash
python src/main.py
```
